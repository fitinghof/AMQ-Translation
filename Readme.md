# Translation Guidelines

This text contains general guidelines for the translations of AMQ to Swedish.

Overall, it was decided to try and make the translations as Swedish as possible, avoiding "Swenglish" as far as possible. Exceptions have still been made and should be described below.

Note that this readme is also a work in progress.

## Specific translation choices

- Ranked - Tävlingsinriktat
- Themed quiz - Tema quiz
- Community - Gemenskap
- Email - E-post / E-postadress (Context dependent)
- Skins - Utklädnader
- Scoreboard - Poängtavla
- Name Change Token - Namnändringspollett

## Don't Translate

- Nexus
- FAQ
- Online / Offline
- Jam
